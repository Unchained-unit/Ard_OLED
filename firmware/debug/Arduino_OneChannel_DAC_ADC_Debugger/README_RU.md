# Одноканальный ручной отладчик MCP4728 + ADS1115

Скетч предназначен для прямой ручной проверки одного канала: задать напряжение на любом выходе MCP4728 и посмотреть напряжение на любом входе ADS1115.

По умолчанию PCA9548A не используется. Если микросхемы подключены через PCA, измените в начале скетча:

```cpp
#define USE_PCA9548A 1
#define ADC_PCA_CHANNEL 0
#define DAC_PCA_CHANNEL 1
```

## Запуск

1. Откройте `Arduino_OneChannel_DAC_ADC_Debugger.ino`.
2. Выберите Arduino и COM-порт её USB-преобразователя.
3. Загрузите скетч.
4. Откройте монитор порта на 9600 baud.
5. Отключите RS-485 A/B во время прямой USB-отладки.

## Быстрая проверка

```text
PING
STATUS
SCAN
ARM
DAC A 0.200
ADCALL 20
ZERO
```

`SCAN` должен увидеть `0x48` (ADS1115) и `0x60` (MCP4728).

`DAC A 0.200` задаёт 0.2 В на выходе A. Реальное напряжение нужно проверить мультиметром. Если выход A соединён с входом A0, команда `ADC 0 20` покажет измеренное напряжение, минимум, максимум и шум.

## Шунт и коэффициенты

Постоянные значения находятся в начале скетча:

```cpp
float shuntOhms = 25.0f;
float currentSenseGain = 10.0f;
float voltageFeedbackScale = 3.0f;
float voltageZeroV = 0.0f;
float currentZeroV = 0.0f;
float photoScale = 1.0f;
float photoZeroV = 0.0f;
```

Их можно изменить прямо из монитора порта без перепрошивки:

```text
SHUNT 25
IGAIN 10
USCALE 3
UZERO 0.0
IZERO 0.0
PSCALE 1
PZERO 0.0
CAL
```

Изменения через монитор действуют до перезагрузки Arduino. Для постоянного значения измените соответствующую строку в скетче.

Назначение каналов по умолчанию:

```text
ADS A0 = измерение напряжения
ADS A1 = усиленное напряжение шунта
ADS A2 = фотоканал
DAC A = уставка напряжения
DAC B = уставка тока
```

Изменить назначение:

```text
MAP 0 1 2
DACMAP A B
```

Получить сразу физические значения:

```text
MEASURE 20
```

Пересчёт выполняется так:

```text
U_SAMPLE = (U_ADC - UZERO) * USCALE
I_MA = (I_ADC - IZERO) / IGAIN / SHUNT * 1000
BRIGHTNESS = (PHOTO_ADC - PZERO) * PSCALE
```

Можно задавать сразу реальную величину. Например, при `USCALE=3` команда:

```text
ARM
SETU 1.5
```

выставит на DAC A примерно 0.5 В. Для тока при шунте 25 Ом и усилении 10:

```text
ARM
SETI 10
```

выставит на DAC B 2.5 В.

## Gain ADS1115

```text
GAIN 2/3
GAIN 1
GAIN 2
GAIN 4
GAIN 8
GAIN 16
```

При gain 16 допустимый измерительный диапазон равен ±0.256 В. Не подавайте на вход напряжение выше питания ADS1115 даже при выбранном диапазоне 6.144 В.

## Sweep

Соедините проверяемый выход DAC с нужным входом ADC. Например, DAC A с ADS A0:

```text
ARM
SWEEP A 0 0.0 1.0 0.1 300
```

Скетч задаст 0...1 В с шагом 0.1 В, в каждой точке сделает десять измерений и напечатает CSV-строки. После завершения все выходы ЦАП автоматически обнуляются.

Для точного расчёта кода DAC измерьте питание MCP4728 мультиметром и укажите его, например:

```text
VREF 4.982
```
