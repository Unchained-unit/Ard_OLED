# Полный отчёт по первому OLED-каналу

Откройте файл `Arduino_Channel1_FullReport.ino` в Arduino IDE и загрузите его в Arduino.

Скетч только читает АЦП и ничего не записывает в ЦАП. Это позволяет увидеть реальные сигналы аналоговой схемы без изменения уставок программой.

## Перед запуском

1. Если MAX485 остаётся подключённым к `TX/RX`, соединённые вместе `DE` и `/RE` должны быть подключены к `D2`.
2. На время USB-отладки отключите линии `A/B` этой платы от общей шины RS-485.
3. Откройте Serial Monitor на скорости `115200 baud`.
4. После перезапуска один полный отчёт выводится автоматически.

## Карта первого канала

- PCA9548A, ветка `0`, ADS1115 `A0`: измеренное напряжение образца через дифференциальный тракт.
- PCA9548A, ветка `0`, ADS1115 `A1`: выход усилителя регистрации тока.
- PCA9548A, ветка `4`, ADS1115 `A0`: фотометрический сигнал первого образца.
- Остальные входы обоих ADS1115 также выводятся для проверки наводок и ошибочной разводки.

## Формула тока

По умолчанию используются фактические значения, которые обсуждались для схемы:

```text
Rшунта = 25 Ом
усиление регистрации тока = 10

Vусилителя_исправленное = V_ADC - I_OFFSET
Vшунта = Vусилителя_исправленное / 10
I_mA = Vшунта / 25 * 1000 * ICAL
```

Например, при `I_ADC = 2.5 В`:

```text
Vшунта = 2.5 / 10 = 0.25 В
I = 0.25 / 25 = 0.01 А = 10 мА
```

## Основные команды

```text
REPORT 16       полный отчёт, усреднение по 16 измерениям
PORTS 16        сырые коды и напряжения на всех входах АЦП
MONITOR 1000    короткая строка значений каждую секунду
FULLMON 5000    полный отчёт каждые 5 секунд
STOP            остановить мониторинг
CONFIG          показать все коэффициенты
SCAN            проверить устройства на всех ветках PCA9548A
```

Коэффициенты можно изменить без перекомпиляции:

```text
SHUNT 25
IGAIN 10
USCALE 3
UOFFSET 0
IOFFSET 0
POFFSET 0
UCAL 1
ICAL 1
PCAL 1
```

Диапазоны ADS1115 для напряжения, тока и яркости задаются отдельно:

```text
UGAIN 2/3
CGAIN 2/3
PGAIN 16
```

Допустимые значения: `2/3`, `1`, `2`, `4`, `8`, `16`.

Изменения команд действуют до перезапуска Arduino. Для постоянного значения измените соответствующую переменную в начале `.ino`-файла.
