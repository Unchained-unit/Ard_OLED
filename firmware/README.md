# Прошивки Arduino

## production

`production/Arduino_RS485_OLEDer/Arduino_RS485_OLEDer.ino` — основная
четырёхканальная прошивка для работы с приложением NMSE OLEDer.

Перед загрузкой на каждую плату укажите уникальный `DEVICE_ID` и реальное
значение `SHUNT_OHMS`. Скорость последовательного порта — 9600 бод. На общей
RS-485-шине прошивка отвечает только на команды со своим адресом.

## debug

### Arduino_RS485_OLEDer_DeepDebug_RS485

Используйте для полной проверки I2C-мультиплексора, ЦАП, АЦП и обмена RS-485.
Описание команд находится рядом с `.ino` в `README_DEBUG_RU.md`.

### Arduino_OneChannel_DAC_ADC_Debugger

Минимальный стенд для ручной установки напряжения на выходах MCP4728 и
наблюдения всех входов ADS1115. Удобен, когда силовая схема ещё не подключена.

### Arduino_Channel1_FullReport

Выводит подробные сырые и пересчитанные значения первого канала: напряжение
ADC, напряжение образца, сигнал токового усилителя, ток через шунт и яркость.

## Важно

Не загружайте отладочную прошивку вместо рабочей на плату, оставленную в
долговременном эксперименте. Перед диагностикой сначала обнулите уставки и
отключите образец, если схема находится в неизвестном состоянии.
