# Готовая Windows-сборка

`NMSE_OLEDer_RS485.exe` — автономная Windows x64-сборка с FastAPI, Uvicorn и
локальным веб-интерфейсом. Установка Python на компьютере пользователя не
требуется.

Сборка 2026-09-25: однократная подстройка тока по показаниям АЦП.
После трёх измерений в допуске ЦАП фиксируется до следующего «Применить».
Допуск задаётся в карточке канала. Описание — `docs/CURRENT_FEEDBACK.md`.
Добавлена вкладка «Ток по платам»: общая уставка для 4 каналов, установка
отдельной платы или всех плат на связи, сброс платы и общий сброс.

Перед запуском закройте Arduino Serial Monitor и другие программы, занимающие
нужный COM-порт.
