# Передача проекта другому человеку

## Что нужно передать

Передайте или клонируйте весь репозиторий:

```text
Ard_OLED
```

Внутри есть:

- исходники backend;
- исходники frontend;
- Arduino-прошивка;
- скрипт тестирования RS-485;
- скрипт сборки exe;
- готовый exe;
- вкладка калибровки коэффициентов;
- управление gain фотоканалов ADS1115.

## Минимальный набор для пользователя без разработки

Если человеку нужен только запуск:

```text
release\NMSE_OLEDer_RS485.exe
firmware\production\Arduino_RS485_OLEDer\Arduino_RS485_OLEDer.ino
README.md
```

## Минимальный набор для разработчика

Нужен весь репозиторий. Исходники приложения находятся в папке `app`.

Требования:

- Windows;
- Python 3.12;
- Arduino IDE;
- библиотеки Arduino:
  - Adafruit MCP4728;
  - Adafruit ADS1X15.

Важно: для управления gain яркости нужно прошить платы свежим файлом `Arduino_RS485_OLEDer.ino`, потому что старая прошивка не знает команду `PHGAIN`.

## Проверка перед работой

1. Прошить платы с разными `DEVICE_ID`.
2. Подключить USB-RS485.
3. Перейти в папку `app` и запустить:

```powershell
cd app
.\.venv\Scripts\python.exe tools\rs485_multi_board_test.py COM3 --boards 1,2
```

4. Если обе платы отвечают `OK,PONG`, запускать интерфейс.

## Важная диагностика

- `PING` есть, `READ` нет: проблема I2C на плате, а не RS-485.
- `STATUS ADS=0,DAC=0`: Arduino не видит ADS/DAC через PCA/I2C.
- `ERR,BAD_GAIN`: в команду `PHGAIN` передан неверный gain. Допустимо `2/3`, `1`, `2`, `4`, `8`, `16`.
- Gain яркости применился, но яркость упёрлась в потолок: выбран слишком узкий диапазон ADS1115, нужно уменьшить gain.
- Нет даже `PING`: проверить TX→DI, RX→RO, D2→DE+/RE, A/B, общий GND, питание.
- Если `A-A/B-B` не работает: поменять A/B местами на USB-RS485.
