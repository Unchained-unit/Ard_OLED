Калибровочные коэффициенты

Arduino передаёт готовые U и I; программа применяет финальную correction и токовый offset, зависящий от напряжения образца.
Скачать JSON
Калибровки автоматически хранятся по RS-485-адресу платы, даже если временно убрать плату из активного списка. Файл настроек: %USERPROFILE%\.nmse_oleder_rs485\config.json.
Для яркости можно выбрать PGA/gain ADS1115. Чем меньше диапазон, тем лучше шаг измерения, но если реальный сигнал выше диапазона, АЦП будет насыщаться.
Линейный offset тока: задайте две точки (U1; I offset 1) и (U2; I offset 2). Между ними поправка меняется линейно и вычитается из тока Arduino. Ниже U1 и выше U2 используется ближайшее крайнее значение.

Памятка подключения

Коротко для передачи проекта в другие руки.
RS-485: USB-RS485 A → общая A, B → общая B, GND общий. На каждой Arduino: TX→DI, RX→RO, D2→DE и /RE вместе, VCC/GND на MAX485. Команды адресные: 1,PING, 2,READ, 3,SET,1,0.8,0.2.
Папки записи: %USERPROFILE%\.nmse_oleder_rs485\recordings\run_YYYY-MM-DD_HH-MM-SS\board_01\sample_1.csv. Для каждой платы создаётся своя папка, внутри 4 CSV.
ADS1115 яркость: gain фотоканала выбирается отдельно для каждого образца. Команда платы: 1,PHGAIN,3,16. Диапазоны: 2/3 → 6.144 В, 1 → 4.096 В, 2 → 2.048 В, 4 → 1.024 В, 8 → 0.512 В, 16 → 0.256 В.
